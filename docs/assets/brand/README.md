# Human-AI flywheel symbol

The development symbol of the project: two curved arrows, indigo and teal, circling three stacked layers. It stands for people and AI turning one flywheel around shared, layered knowledge.

| File | Use |
|---|---|
| `flywheel-512.png` | large pictures, social preview source |
| `flywheel-256.png` | README and documentation headers (shown at 96 to 128 px) |
| `flywheel-128.png` | small inline use |

All files are square PNGs with a transparent background.

| Colour | Hex |
|---|---|
| Indigo | `#301382` |
| Teal | `#05A58C` |

Below about 48 px the thin arrows blur; a simplified variant for favicons and app icons is still to come.
